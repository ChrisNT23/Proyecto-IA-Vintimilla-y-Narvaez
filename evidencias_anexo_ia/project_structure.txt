Estructura del Proyecto MoCA AI v2.0
=======================================

/
├── backend/                   # Servidor Node.js (API Principal)
│   ├── controllers/           # Lógica de negocio de la MoCA
│   ├── model_server.py        # Microservicio de IA (Flask + TF)
│   ├── services/              # Integración con modelos Emotion/CNN
│   ├── data/                  # Datasets de entrenamiento (Cubo/Reloj)
│   ├── models/                # Modelos H5 y Keras locales
│   └── utils/                 # Análisis cognitivo-emocional
├── frontend/                  # Interfaz de usuario (React)
│   ├── src/
│   │   ├── screens/
│   │   │   ├── MOCAmodules/   # Actividades interactivas
│   │   │   │   ├── Visuoespacial.jsx # Tests Cubo/Reloj
│   │   │   │   └── Atencion.jsx      # Captura emocional
│   │   │   └── Dashboard/     # Visualización multimodal
├── models/                    # Modelos finales (Emotion Final)
├── reports/                   # Métricas y gráficas de evaluación
└── evidencias_anexo_ia/       # Carpeta de evidencias (Anexo Tesis)
